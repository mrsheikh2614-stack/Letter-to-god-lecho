A Letter to God - Class 10 MCQ Test

20 MCQs, 1 mark each.

After submission, the quiz changes to a separate result page showing:
- Total score
- Correct answers
- Wrong answers
- Percentage
- Question-by-question answer review
- User answer and correct answer

For GitHub Pages:
1. Upload index.html to a GitHub repository.
2. Go to Settings > Pages.
3. Select Deploy from a branch.
4. Select main and / (root), then Save.
